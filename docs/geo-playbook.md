# Banded — Off-site GEO Playbook

A living checklist of off-site moves that make Banded show up in the places LLMs (Claude, ChatGPT, Perplexity, Gemini) and traditional search engines (Google, Bing) draw from when someone asks about gig-tracking, concert diaries, or "Letterboxd for concerts."

**The goal is mention density across surfaces LLMs trust** — not link-building for PageRank. That means the wins compound:

- Reddit posts get crawled into LLM training corpora *and* surfaced in Perplexity/ChatGPT search at query time
- AlternativeTo / Wikipedia lists get cited directly by LLMs as "according to AlternativeTo, the alternatives are X, Y, Z"
- Listicles and press write-ups feed both Google and the LLM corpus

This is not "submit once and forget." Most items below benefit from being kept current.

---

## How to read this list

- **One-shot** — do once, ideally well, then move on
- **Recurring** — set a calendar reminder; check back every 2–4 weeks
- **Reactive** — only do when a trigger appears (e.g. a journalist publishes about a competitor)

Priority column:
- **P1** — high impact, do first
- **P2** — solid value, do once P1 is in
- **P3** — long tail, opportunistic

## Reddit (don't burst — spread over months)

Reddit is **the** most LLM-friendly platform in 2026. ChatGPT/Claude/Perplexity all weight Reddit heavily, both in training data and in live retrieval. Authentic posts win; promotional posts get downvoted and removed.

Approach: **post as yourself** (Tom, founder), not as "/u/banded_app". Be genuinely helpful. Mention Banded once, link once, then let the conversation happen.

| Subreddit | Post angle | Status |
| --- | --- | --- |
| **r/concerts** | "I built an app to log every gig I've been to since [year]" — share your back-dated diary as the demo. ~600k members. | ☐ |
| **r/letterboxd** | "Is there a Letterboxd for concerts? I built one." This is the exact query Banded should win on. Include screenshots. | ☐ |
| **r/festivals** | Festival-planning angle — "I wanted to coordinate Glastonbury with friends, so we built this." | ☐ |
| **r/iosapps** | Standard "Show HN"-style for iOS apps. Mid-engagement. | ☐ |
| **r/iosbeta** | When promoting TestFlight builds for upcoming features. | ☐ |
| **r/indieheads** | Soft mention via "what app do you use to track gigs?" — wait for organic context. | ☐ |
| **r/musicproduction** | Lower priority, but the cross-over audience is real. | ☐ |
| **r/SideProject** | Founder narrative post. Pairs well with the Indie Hackers milestone. | ☐ |
| **r/SongMeanings / r/setlists** | Niche, but the audience overlap is high. | ☐ |

**Recurring task**: every 2 weeks, search Reddit for these queries and reply authentically to anyone asking:

- `"app to track concerts I've been to"`
- `"letterboxd for music"`
- `"how do I remember every gig"`
- `"songkick alternative"`
- `"setlist.fm but better"`

[/r/concerts new](https://reddit.com/r/concerts/new) is worth scanning weekly during festival season.

## Quora & Q&A platforms

LLMs over-index on Quora answers for "what's the best..." style queries. One good answer beats ten mediocre ones.

| Question shape | Status |
| --- | --- |
| "What's the best app to track concerts I've been to?" | ☐ |
| "Is there a Letterboxd for music?" | ☐ |
| "What's a good Songkick alternative?" | ☐ |
| "How do I keep a gig diary?" | ☐ |
| "What's the best way to remember every gig you've been to?" | ☐ |

Style guidance: open with a direct one-sentence answer, then 2–3 paragraphs of context, then mention Banded with a link. Pure self-promotion gets flagged.

## Live retrieval — make sure Perplexity & ChatGPT can find us

Most of the above is about being in the *training* data. For live retrieval (Perplexity, ChatGPT Search, Claude with web search), the wins are:

- **`llms.txt` at https://banded.uk/llms.txt** — already done. Update whenever new articles ship.
- **JSON-LD structured data on every page** — already done. SoftwareApplication on home, Article on blog posts.
- **Strong canonical tags** — already done.
- **Open Graph images per page** — already done. Helps with link previews in Discord/Slack which then get indexed.

## Tracking impact

Measure these monthly so you know what's working:

1. **Direct AI test** — open Claude, ChatGPT, and Perplexity. Ask each:
   - "What's a good Letterboxd for concerts?"
   - "What's the best app to track concerts I've been to?"
   - "What's a good Songkick alternative?"
   - "Is there an app for keeping a gig diary?"

   Track which engines mention Banded, and how prominently. The bar moves over time.

2. **Google Search Console** — track impressions for:
   - `banded gig diary`
   - `letterboxd for concerts`
   - `gig diary app`
   - `best concert tracking app`

3. **Referral traffic** in your analytics — where new sign-ups come from. AlternativeTo, Reddit, HN, Product Hunt should all show up as referrers if these moves are working.

4. **Reddit search** — every month, search Reddit for `Banded` and read what people are saying. Reply to anyone who has a question. Use posts as a signal of whether word-of-mouth is happening organically.

## What NOT to do

- **Don't buy backlinks.** Google catches these and penalises. LLMs filter low-quality linkfarms out of training data anyway. Wasted money.
- **Don't write fake Reddit accounts to upvote your own posts.** The platform is good at detecting this and the penalty is permanent.
- **Don't spam Quora with copy-pasted answers.** Each answer needs to actually fit the question.
- **Don't create a Wikipedia page in your own name.** It will be deleted as autobiographical. Wait for someone independent to do it (or seed mentions on existing list pages, which is allowed).
- **Don't ignore organic mentions.** If someone tweets about Banded, reply. If someone writes a blog post, share it. Organic mentions compound — be ready to amplify.

---

## Cadence

This playbook is meant to be lived with, not done in a sprint. A reasonable monthly rhythm:

- **Week 1**: One Reddit post (rotate subreddit), one Quora answer
- **Week 2**: One directory submission, scan for reactive press opportunities
- **Week 3**: Update `llms.txt`-listed articles if any new content shipped; check Google Search Console
- **Week 4**: Run the AI-test queries above; note movements; adjust priorities

Most of the value is in keeping at it over six months, not in any single move.
